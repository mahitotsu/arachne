## system prompt の Java 文字列リテラル（ArachneOrderIntentPlanner.java）

`order-intake-agent` の system prompt は `ArachneOrderIntentPlanner` クラス内の private メソッドとして実装されています。プレーンテキストの自然言語ではなく、**やること / やってはいけないこと** を明示した構造を持ち、エンジニアがレビュー可能な形で管理されています。

```java
// ArachneOrderIntentPlanner.java
private String systemPrompt() {
    return """
            あなたは order-service の order-intake-agent です。
            あなたの責務は customer の注文意図を正規化し、
            menu-service へ catalog grounding 用の構造化 handoff を返すことです。

            やること:
            - DIRECT_ITEM / RECOMMENDATION / REORDER / REFINEMENT のどれかを intentMode に設定する
            - customerMessage に workflow 全体で保持すべき意図の要約を書く
            - menuQuery に menu-service が catalog grounding に使う query を書く
            - directItemHint は明示的な商品指定があるときだけ入れる
            - recentOrderSummary は再注文文脈が必要なときだけ入れる
            - rationale には短く理由を書く

            やってはいけないこと:
            - 具体的な商品 ID や最終提案商品を決めない
            - 在庫や調理可否を判断しない
            - 配送や支払いの意思決定をしない

            人数・予算・子ども人数などの構造化制約は失わずに保持してください。
            最終回答は structured_output のみを使って返してください。
            """;
}
```

このメソッドは git の管理下にあります。prompt に変更が加わると `git diff` に現れ、コードレビューの対象になります。

## ロケールを参照したデプロイ環境依存の注入（OrderApplicationService.java）

`order-service` の system prompt にはサーバーロケールに基づいた言語設定が含まれており、`Locale.getDefault()` を使って実行時に注入されます。

```java
// OrderApplicationService.java（system prompt 構築の抜粋）
String language = Locale.getDefault().getDisplayLanguage(Locale.ENGLISH);
String systemPrompt = """
        ...
        応答言語: %s
        ...
        """.formatted(language);
```

この実装により、デプロイ環境の JVM ロケールを変えるだけで応答言語が切り替わります。変更はコードに記録されるため、どのコミットで言語制御が追加されたかが追跡できます。

## /agents ページでの可視性

`order-service` は起動時に system prompt を含む service descriptor を `registry-service` に登録します。

```java
// OrderServiceConfiguration.java（登録の抜粋）
Map.of(
    "agentName", "order-intake-agent",
    "systemPrompt", "注文意図を正規化し、menu-service への catalog grounding を起動する。",
    ...
)
```

`/agents` ページの「概要」タブはこの registry 登録内容を表示しており、デプロイ済みの system prompt をブラウザから直接確認できます。

## 観察された振る舞い

- `/agents` ページの「概要」タブで、各サービスに登録されている system prompt がそのまま読めた。
- `order-service` の prompt にはサーバーロケールを反映した言語設定が含まれており、JVM ロケールを変えると応答言語が切り替わることをコードから追えた。
- system prompt の変更は `git log` と `git diff` で確認でき、いつ・どの理由で変わったかがレビュー可能な形で残っていた。
- **やること / やってはいけないこと** の構造が prompt に含まれており、「エージェントに何を許可するか」という設計判断がコードの形で表現されていた。

## 確認できる場所

- `/agents` ページの「概要」タブ（各サービスの system prompt）
- `order-service` の `ArachneOrderIntentPlanner.java`（`systemPrompt()` メソッド）
- `order-service` の `OrderApplicationService.java`（ロケール注入の実装）
