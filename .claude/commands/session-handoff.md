次のセッションにそのまま貼り付けられる引き継ぎプロンプトを生成する。コードブロック1つだけを返す。

$ARGUMENTS

このコマンドはファイルを作成・編集・削除・メモリ更新・git操作しない。

## 手順

1. `git status --short` と `git log --oneline -5` で現在のgit状態を確認する。
2. `memories/repo/status.md` を読み、今セッションの作業意図を確認する。
3. 現在の会話・git状態・変更ファイルから、このセッションで何が進み、何が残っているかをまとめる。
4. スコープ外のTODOを引き込まない。確認済み事実のみ記載し、未確認は `unconfirmed` と明記する。
5. 引き継ぎプロンプトには最低限以下を含める:
   - 継続テーマまたは現在のゴール
   - 最初に読むべきファイル
   - このセッションで完了したこと
   - 未解決・ブロック中・リスクのある事項
   - 最初の具体的な次アクション
   - 再実行すべき検証コマンド

コードブロック1つだけを返し、それ以外は出力しない。
